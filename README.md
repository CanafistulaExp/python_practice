# python_practice
Exercícios e práticas de Python durante minha jornada de aprendizado.

Repositório criado para registrar minha evolução em Python.

## Sobre
Contém exercícios práticos desenvolvidos durante meus estudos de programação, com foco no aprendizado dos fundamentos da linguagem Python.

### Conteúdos estudados
- Variáveis e tipos de dados
- Operadores
- Estruturas condicionais
- Laços de repetição (for e while)
- Funções
- FizzBuzz
- Fundamentos de Listas

## Objetivo
Praticar programação, desenvolver o raciocínio lógico e documentar minha evolução como estudante de Ciências da Computação.

**Linguagem principal:** Python
